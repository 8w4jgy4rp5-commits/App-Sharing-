# 10倍株の分解式（探し方の教材）

作成日: 2026-08-25 / Artifact: https://claude.ai/code/artifact/22f54013-7bfd-4902-bda2-0d937e1ad4ee
※ ユーザーの真の目標が判明: **10年20年で株価が何倍にもなる銘柄**。銘柄提示より先に「探し方」を学ぶ選択

## 分解式（これが全部）

**株価の倍率 = 売上の倍率 × 利益率の倍率 × PERの倍率 ÷ 株数の倍率**

（株価 = EPS × PER、EPS = 売上 × 利益率 ÷ 株数 から導出）

10倍への道は一つではない:
| 売上 | 利益率 | PER | 結果 |
|---|---|---|---|
| 10倍 | 1.0 | 1.0 | 10倍（最も分かりやすいが最も難しい） |
| 4倍 | 1.5 | 1.7 | 10.2倍（**最も現実的**） |
| 2倍 | 2.0 | 2.5 | 10倍（神戸物産がこの型） |

## 何倍を何年で = 必要年率

| 目標 | 年率 |
|---|---|
| 10年で3倍 | 11.6% |
| 10年で5倍 | 17.5% |
| **20年で10倍** | **12.2%** ← 時間があれば爆発的成長は不要 |
| **10年で10倍** | **25.9%** ← 高成長企業しか届かない別ゲーム |
| 20年で20倍 | 16.2% |

## 4つの部品

1. **売上の倍率** — 唯一嘘をつきにくい。年20-30%が**続いているか**（速さより持続性）。年20%で10年6.2倍、年30%で13.8倍 → **自分で確認可**
2. **利益率の倍率** — 上昇 = 規模の経済が効いている。売上が伸びて利益率が下がる会社は値引きで売上を買っている疑い。**装置産業・インフラ・工事が伸びにくい理由もここ** → **自分で確認可**
3. **PERの倍率** — 市場が決める。①②の**後からついてくる**。PER上昇を当てにして買わない → **他人の気分**
4. **株数の倍率** — 唯一の割り算。増資で薄まる。「売上3倍なのに株価1.5倍」の犯人はたいていこれ → **自分で確認可**

→ **3つは決算書の事実、1つだけ運。だから「①②④が揃った会社を、PERがまだ低いうちに買う」のが構造的に有利**

## 実例

### 神戸物産（業務スーパー）— 売上2倍で株価60倍
2012年ごろ60円前後（分割調整後）→ 2020年12月に3,710円の上場来高値 = **約60倍**。
一方 **売上は10年で2倍ちょっと**（2020年10月期3,408億円）。
→ **60倍のうち売上が説明できるのは2倍分だけ。残り約30倍は利益率とPERの変化。**
→ **「売上が10倍になる会社」を探さなくても10倍株にはなる。**

### MonotaRO — 10年で100倍超、PERは常に40〜60倍
株価は10年前比100倍以上、楽天の時価総額も超えた。
**PERは常に市場平均(15倍前後)を大きく上回り40〜60倍**で取引されるのが珍しくない。
→ **高PERは10倍株の「敵」ではなく「結果」。**
→ **これまで私が「PERが高いから割高」として何度も候補を外してきたが、10倍株の文脈ではその基準が最初に候補を全部殺す。**
　 判断すべきは「PERが高いか」ではなく**「その高さに見合う成長が続くか」**

## 自分でやる手順（上から順に、引っかかったら捨てる）

1. **時価総額** — 足切り1,000億円未満、できれば500億円以下（大きすぎたら物理的に無理）
2. **売上の推移5年分** — 年20%以上が数年続いているか
3. **営業利益率の推移5年分** — 横ばい以上、理想は右肩上がり
4. **発行済株式数の推移** — 増えていない（減っていれば加点）※見落としやすい
5. **配当性向** — 40%以下。無配でも問題ない
6. **大株主** — 創業者が大株主として経営しているか（有報の大株主欄）
7. **市場規模(TAM)** — 「今の売上 ÷ 市場規模」が小さいほど伸びしろ

## 何が10倍株を殺すか

- **掛け算が同時に逆回転する** — 成長が止まると①売上鈍化②利益率低下③PER低下が同時に効き、簡単に1/3になる。
  → **年1回「成長が止まっていないか」の確認が必須。バリュー株のように放置できない**
- **途中で必ず何度も半値になる** — 100倍のMonotaROも例外ではない。
  → **「なくなっても生活が変わらない金額」で買う。生活費が入ると最安値で売ることになる**
- **多くは失敗する** — 10倍株の話は成功例しか語られない（生存者バイアス）。
  → **1社に賭けず複数持つ。10社買って1社10倍・3社半減でも全体では勝てる**

## これまでの私の分析との関係（重要な自己批判）

**「PERが低い」「配当が高い」「連続増配」「安定」を良い条件として使ってきたが、10倍株の文脈では全部逆のサイン。**
- 高配当 = 利益を再投資していない
- 低PER = 市場が成長しないと判断した価格
- 連続増配 = 成熟企業
- 安定 = 伸びていない

**これまで調べた約30社を「売上年20%成長」で切ると1社も残らない。**
最も近いメタウォーター(+17.2%)と朝日工業社(+14.0%)でも届かず。
理由: **DC・電力・水は資本集約的で、売上2倍にするには設備も人も2倍要る**ため構造的に年20%成長しにくい。

## 注意

この式は**過去を後から分解すれば必ず説明がつく**が、**これから10倍になる会社を事前に当てられるという意味ではない**。
式が保証するのは「どこを見るべきか」であって「当たること」ではない。
