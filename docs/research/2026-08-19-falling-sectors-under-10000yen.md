## 0. 使う指標 — 「株価の下落」と「利益の方向」を分けて見る

「落ちている」には**性質の違う4種類**があり、これを混ぜると判断を誤ります。今回はこの分類を軸にしました。

| | **利益が伸びている** | **利益が減っている** |
|---|---|---|
| **株価が下落** | **① センチメント下落** = 買い場の可能性 | **② 構造的下落** = バリュートラップ警戒 |
| **高値からの下落(1年では上昇)** | **③ 過熱の調整** = まだ高い可能性 | **④ 個別要因の下落** = 業種は上がっているのに1社だけ |

各社について次の5点を調べました。
1. 下落は**業種全体**か**個別**か
2. **利益の方向**(増益か減益か)
3. 下落の理由が**センチメント**か**ファンダメンタルズ**か
4. **買える条件**(何を確認できたら下げ止まりと判断できるか)
5. リスク

### ① 清水建設 (1803) — 「業績は最高、株価は最安」

| 項目 | 内容 |
|---|---|
| 株価 | **¥2,285.5**(-4.23%) |
| PER | **9.47倍**(ゼネコン4社で最安) |
| 配当利回り | 3.18% |
| 時価総額 | ¥1.62兆 |
| アナリスト | Buy(7名)、目標 **¥3,014(+31.9%)** |

**下落の種類**: 業種全体。大成-4.41%、鹿島-4.27%、大林-3.92% と4社同時。

**利益の方向**: **強い増益**。純利益予想を **1,100億円(+67%)** へ大幅上方修正、利益成長率 **+91.8%** は4社で最大。売上¥2.06兆(+5.83%)。

**下落の理由**: **センチメント**。①中東情勢による資材の供給・値上げ懸念 ②AI関連への資金集中で「置き去り銘柄」化(6月2日には年初来安値が360銘柄超) ③日経平均全体の調整。**業績を否定する材料は出ていません**。

**買える条件**:
- 四半期ごとの**完成工事総利益率**が改善を続けているか(ゼネコンは不採算工事の一括計上で決算が突然崩れる業種)
- 手持ち工事高(受注残)が減っていないか
- 資材価格と労務費の上昇を**価格スライドで転嫁できているか**

**リスク**: 不採算工事の突発計上。資材・労務費の転嫁遅れ。建設需要は大型案件の完成集中に依存しており、その波が切れると反動減が出る。

### ② ナイキ (NKE) — 「安く見えるが、まだ落ちている」

| 項目 | 内容 |
|---|---|
| 株価 | **$41.12(¥6,563)** |
| PER | 19.08倍 |
| 配当利回り | **4.00%** |
| 時価総額 | $61.0B(**-46.3%**) |
| 株価推移 | **1年で-50%、2026年だけで-38%、2014年以来の安値** |
| アナリスト | Hold、目標 $50.66(+23.2%) |

**下落の種類**: 業種全体(Consumer Discretionaryは**年初来ワーストセクター**)+ 個別の重い問題。

**利益の方向**: **減益**。FY2026は売上$46.40B(+0.19%)、利益 -3.45%の$3.11B。**EBIT率は6.2%まで低下**。

**下落の理由**: **ファンダメンタルズ**。
- **中国が崩れている**: Greater Chinaの売上はFY2026に-11%、当四半期はさらに**-20%の減収見通し**。2021年比では**-30%**
- **Anta・Li Ningとの競争激化**。中国市場でローカルブランドに負けている
- 最大の中国小売パートナー **Topsports が2027年1月までにオンライン販売を停止**
- CEO Elliott Hill(「Win Now」戦略)は**「立て直しは想定より長くかかっている」**と認めた。回復はFY2027(来春)まで続く見通し
- **JPMorganが Underweight へ格下げ**

**買える条件**:
- **中国の減収率が縮小に転じること**(-20% → -10%台へ)。ここが最重要
- 在庫の正常化と**粗利率の回復**(会社は FY2028に46%まで戻す計画)
- 卸売パートナーとの関係修復が売上に表れること

**リスク**: **典型的なバリュートラップの形**をしています。「1年で半値、配当4%」は魅力的に見えますが、**利益が下向きの間はPERが低くても意味がありません**。ただしEBIT率6.2%は歴史的な谷であり、正常化(10年で17%目標)すれば戻り幅は大きい ← 米トラック運送のWERNと同じ構図です。

### ③ SUMCO (3436) — 「落ちている」の意味が他と違う

| 項目 | 内容 |
|---|---|
| 株価 | **¥3,517**(-7.15%) |
| **1年騰落** | **+178.9%** |
| 52週レンジ | ¥— 〜 **¥5,939**(高値から**-41%**) |
| 純損益 | **-277億円(赤字)** |
| 配当利回り | 0.53% |
| アナリスト | Hold(16名)、目標 ¥3,908(+11%) |

**下落の種類**: 業種全体(半導体の1兆ドル消失)。ただし**1年では+178.9%**なので、これは「下落」ではなく**過熱の調整**です。ルネサス(-9.06%、1年+90.4%)、日本電気硝子(-5.85%)も同じ日に下げています。

**利益の方向**: **赤字だが底打ちが近い**。ここが面白い点で、**事業が二極化**しています。
- **AI向け300mmウェハーは好調**: 2026年1-3月の世界ウェハー出荷面積は**前年同期比+13%**。業界3強(信越化学・SUMCO・環球晶円)が**2026年上半期に2回値上げ、累計15%超**
- **200mm以下のレガシー品は在庫調整が継続**: 自動車・民生向けが低迷
- 経営陣は「**顧客の在庫調整はほぼ終了、2026年後半から本格的な需給逼迫が懸念されるレベルの回復**」を見込む

**買える条件**:
- **黒字転換の確認**。赤字のまま株価が3倍近くになっており、業績が後から追いつくかどうかが全て
- レガシー(200mm)の在庫調整完了が数字に出ること
- 長期契約の価格改定が実際に売上単価に反映されること

**リスク**: **「業績より先に株価が動きすぎた」典型**。1年+178.9%で赤字という組み合わせは、期待が実力を大きく超えている状態です。AI投資の減速懸念が続けば、下値は-41%では止まらない可能性があります。**5社の中で最もリスクが高い**。

### ④ ヤマトHD (9064) — 「同業が上がる中、1社だけ落ちた理由」

| 項目 | 内容 |
|---|---|
| 株価 | **¥1,915.5** |
| PER | 46.25倍(予想27.67倍) |
| 配当利回り | 2.36% |
| 1年騰落 | **-21.3%** |
| アナリスト | Hold、目標 ¥1,788(**-6.7%**) |

**下落の種類**: **個別要因**。物流業界は2024年問題で運賃が上がり、**福山通運は1年でほぼ倍化、セイノーHDは+19.7%**。その中でヤマトだけが下落しています。

**利益の方向**: **明確な悪化**。
- FY2026/3の営業利益は **283億円**(期初予想を**116億円下回る**)、純利益は **-60%の150億円**
- **26年4-6月期は58.87億円の最終赤字。四半期ベースで4期連続の赤字**
- TTM純利益は **-69%**

**下落の理由**: **ファンダメンタルズ**。
- **大口法人の取扱数量が想定を下回った**。物価高で消費意欲が減退し荷動きが鈍い
- **「コストの下方硬直性」が顕在化**: 荷物は減るのに人件費は高止まりで固定される。オペレーティングコストの適正化遅れによる減益額だけで**98億円**
- 中期経営計画の目標を大幅下方修正(「営業利益は当初想定の半分以下」)

**構造改革は進行中**:
- クロネコDM便・ネコポスといった**低採算事業から撤退**
- **日本郵政と協業**して配達網を活用するモデルへ転換、**約3万人分の委託契約を整理**
- 新社長(桜井氏)が「稼ぐ力の抜本的再構築」を掲げ、**FY2027/3に営業利益420億円必達**を宣言

**買える条件**:
- **420億円の必達目標に対する進捗**(四半期ごとに確認)
- **四半期赤字が止まること**(現在4期連続)
- 宅急便の取扱数量が前年を上回ること

**リスク**: 「業種が良いのに1社だけ悪い」= **業界の追い風では救われない構造問題**を抱えているということ。アナリスト目標が現値より**-6.7%下**という点は重く見るべきです。**現時点では推奨できません**が、構造改革が効き始めた瞬間の変化率は大きい銘柄です。

### ⑤ 北海道電力 (9509) — 「1年下落 × 最大の上値余地」

| 項目 | 内容 |
|---|---|
| 株価 | **¥1,046**(-2.01%) |
| PER | 8.70倍(予想7.67倍) |
| 配当利回り | 3.12% |
| 時価総額 | ¥219B(電力大手で最小級) |
| 1年騰落 | **-8.25%**(電力10社で唯一の下落) |
| ベータ | **0.37**(値動きが穏やか) |
| アナリスト | Hold(3名)、目標 **¥1,390(+32.9%)** |

**下落の種類**: **個別要因**。九州電力(+23.9%)、セイノー等が上がる中で唯一下げています。

**利益の方向**: **足元は悪化**。26年4-6月期は売上+5.9%の2,144億円に対し、**営業利益-44.3%(244億円)、経常利益-55.0%(187億円)**。

**下落の理由**: **ファンダメンタルズ + 財務リスク**。
- **泊原発がまだ動いていない**。防潮堤の完成が**2027年8月見込み**で、再稼働はその後
- **2.4兆円の投資負担**: 2025〜35年度の11年間で泊原発と送配電設備に投資。日経は「**もろ刃のラピダス効果**」と表現し、財務リスクを指摘

**それでも注目する理由 — 需要の触媒が他社にない規模**:
- **ラピダス(千歳)の工場4棟がフル稼働すると約60万kW**。これは**北海道の最大電力需要の約1割**に相当
- **ソフトバンクが苫小牧に国内最大級のDC**を建設予定、**石狩市もDC集積地**
- 合計すると中長期で **120万kW超の需要創出**見込み
- つまり「北海道は原発なしでは電力がギリギリ」という状態であり、**泊原発の再稼働と需要増が同時に来る**構図

**買える条件**:
- **泊原発の防潮堤完成(2027年8月)と再稼働のスケジュールが前倒し・確定すること**。これが最大のカタリスト
- ラピダスの稼働開始と実際の受電契約
- 2.4兆円投資に対する**財務の健全性**(自己資本比率・格付け)

**リスク**: 再稼働がさらに遅れれば、2.4兆円の投資が先に重くのしかかります。**「触媒は最大、財務リスクも最大」**という銘柄です。時価総額¥219Bと小さいため値動きも荒くなります。

## 3. まとめ — 5社の順位づけ

| 順位 | 銘柄 | 分類 | 理由 |
|---|---|---|---|
| **1位** | **1803 清水建設** | ① センチメント下落 | **利益+91.8%なのに業種もろとも売られている**。下落の理由が業績にない唯一の銘柄。PER9.47倍・利回り3.18%・目標+31.9% |
| 2位 | **9509 北海道電力** | ④ 個別下落 | 触媒(ラピダス+DC+泊再稼働)が5社で最も具体的。ただし**2027年8月以降**の話で、時間がかかる |
| 3位 | **NKE ナイキ** | ② 構造的下落 | 谷は深い(EBIT率6.2%)が、**中国が下げ止まる証拠がまだ無い**。落ちてくるナイフ |
| 4位 | **3436 SUMCO** | ③ 過熱の調整 | 需給の話は本物だが、**赤字のまま1年+178.9%**は期待先行。下値余地が読めない |
| 5位 | **9064 ヤマトHD** | ④ 個別下落 | **業種の追い風で救われていない**時点で構造問題。4期連続赤字、アナリスト目標は現値より下 |

### この5社から学べること

**「株価が落ちている」だけでは何の情報にもなりません。** 判断を分けるのは次の2つです。

1. **利益は上を向いているか、下を向いているか** — 清水建設(+91.8%)とヤマトHD(-69%)は、同じ「下落銘柄」でも意味が正反対です
2. **業種全体か、その1社だけか** — 業種全体なら他社と比べて評価でき、1社だけなら「なぜその1社だけなのか」に必ず答えがあります(ヤマトHDのコストの下方硬直性、北海道電力の泊原発)

**最も安全なのは「利益が伸びているのに業種もろとも売られている銘柄」**(=①)。今回それに該当するのは清水建設だけでした。
