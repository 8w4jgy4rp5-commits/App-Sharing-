## 0. 結論 — 信憑性ランキング

| 順位 | テーマ | 信憑性 | 一言 |
|---|---|---|---|
| **1位** | **電力** | ★★★★★ | AIの真のボトルネック。20年契約の受注書がすでに存在する |
| 2位 | データセンター本体 | ★★★★☆ | 需要は本物だが、資金が借金と循環取引に寄りかかり始めた |
| 3位 | 水インフラ | ★★★☆☆ | 本物だが規模が小さく、「水の量」ではなく「水処理サービス」に価値が寄る |
| 4位 | フィジカルAI | ★★☆☆☆ | 方向は正しいが3〜5年早い。株価だけ先に到達済み |
| **5位** | **メタバース** | ★☆☆☆☆ | トレンドとしては**すでに終了**。ただし「スマートグラス」に姿を変えて生き残った |

### 信憑性を判定した4つの基準

1. **発注書があるか**（期待ではなく、契約・受注残として存在するか）
2. **お金がどこから出ているか**（自己資金 > 借金 > 循環取引）
3. **物理的なボトルネックか**（代替できないものほど強い）
4. **株価にどれだけ織り込まれたか**（正しいトレンドでも高値で買えば負ける）

この4基準で見ると、**電力が全項目で最上位**になります。理由は次章。

## 1位: 電力 — 「AIのボトルネックは電力」

### なぜ最も信憑性が高いか

- **需要が物理法則で決まる**。GPUを動かせば必ず電気を食う。ソフトウェアと違って「使わない選択」がない
- **すでに20年契約が結ばれている**。Constellation は Meta と Microsoft に原子力を供給する契約、Vistra は Meta と20年契約 — 期待ではなく**署名済みの契約書**
- **供給が絶望的に間に合わない**。発電所も送電網も変圧器も、建てるのに5〜10年かかる。GPUは18か月で作れるが、電気は作れない
- BloombergNEF: データセンターは**2035年に米国の総電力の1/5**を消費(現在約6%)。米国の1人あたりDC電力消費は540kWh(2024) → 1,200kWh(2030)
- **AI以外の需要も同時に来ている**(EV、製造業の国内回帰、猛暑による空調)。仮にAI投資が止まっても需要がゼロにはならない ← ここが他の4テーマとの決定的な違い

## 2位: データセンター本体 — 需要は本物、資金繰りが論点

### ファクト

- **ハイパースケーラー4社の2026年capex: $630B(+62%)〜$725B(+77%)**
  - Amazon $200B / Google $175-185B / Meta $115-135B / Microsoft $110-120B
  - うち約75%(≒$450B)がAI関連
- 「シリコンのボトルネックは終わり、**コンクリート・銅・冷却がボトルネック**になった」
- 事業者は「需要に供給が追いつかない」と言い続けている

### ただし、ここが最大の警戒点(AI capexバブル論)

| 論点 | 内容 |
|---|---|
| **capex強度** | 上位5社のcapexは売上の**34%**。1990年代インターネットバブルのピーク(15%)の**2倍以上**。フリーキャッシュフローが35年ぶりにマイナス転落 |
| **循環取引** | NVIDIA / OpenAI / Oracle / CoreWeave の間で、ベンダー出資・take-or-pay契約・GPU担保の借入が絡み合う。**1999〜2001年の Lucent / Nortel のベンダーファイナンスと同じ構図**という指摘 |
| **減価償却** | GPUの減価償却率は年20%〜初年度30-40%という試算。3年で価値50%、5年で20%。Alphabetの減価償却費は4年で約$57B増加すると予想され、利益率を直撃 |
| **市場の反応** | 2026年7月、Alphabetの決算を受けてGoogle・Amazon・Microsoftが揃って売られた。投資家はすでに疑い始めている |
| PIMCO(2026年5月) | 「AIは本物のリスクを伴うcapexブームの只中にある — 収益化の不確実性、過剰建設、資産寿命の短縮、借入依存の拡大」 |

**読み方**: 需要が嘘なのではなく、**「今の投資ペースを何年続けられるか」が問題**。したがってDCテーマは「トレンドの正しさ」より「どこで買うか」が決定的に重要になります。

## 3位: 水インフラ — 本物だが規模が小さい

前回調査(`2026-08-18-cyclical-trucking-water.md`)の要点 + 日本株の補足です。

- DC向け水・排水処理機器市場: 2026年 **$3.30B** → 2031年 $5.90B(CAGR 12.3%)
- **規模感が電力の1/100以下**。「水が儲かる」より「水**処理サービス**が儲かる」が正しい理解
- 注意: **液冷 ≠ 水消費増**。閉ループ設計なら水は減る。価値は水量ではなく薬品・膜・監視のリカーリング収益に寄る

## 4位: フィジカルAI — 方向は正しいが、株価が3〜5年先回りしている

### ファクト(良いニュース)

- Counterpoint Research: 商用稼働するヒューマノイドは**2025年末の16,000台 → 2026年に50,000台超**
- NVIDIA ジェンスン・ファンがCES 2026で「**フィジカルAIのChatGPTモーメントが来た**」と宣言
- 実際の配備: Tesla Optimus(フリーモント工場のシート組立)、Figure AI(BMW)、Boston Dynamics Atlas(Hyundai)
- 日本は**国策**。高市政権の「AI基本計画」でフィジカルAIが中核。官民投資1.5兆円(報道により10兆円超という数字も)

### ファクト(悪いニュース)

- **稼働はすべて「管理された環境で人間の監視付き」**。マーケティングが語る「自律的な汎用作業者」とのギャップは依然大きい
- 予測市場は **Optimusが2026年中に意味のある規模で出荷される確率を14%** と見積もっている
- 決定的な症状: **ファナックは2026年7月31日に好決算+通期上方修正を出したのに、翌営業日に株価が-14.31%**。これは「良い決算では足りないほど期待が膨らんでいた」典型的なサイン

## 5位: メタバース — トレンドとしては終了、ただし形を変えて生存

### 「メタバース」は死にました

- Meta の Reality Labs は **2026年Q2だけで$4.6Bの赤字**。2020年末からの**累計赤字は約$88B(13兆円)**
- 2026年1月、Reality Labs で**約1,500人(部門の10%)を削減**、ゲームスタジオ3社を閉鎖
- **Horizon Worlds はメンテナンスモードに移行**(=事実上の店じまい)
- ザッカーバーグ自身が生成AIへ大きくピボット
- **VR/MRヘッドセットの出荷台数は2025年に-42.8%**

### ただし「スマートグラス」として生き残った

- 2025年のXR出荷は**+44.4%成長**。ただし牽引したのは**VRではなくスマートグラス**。ディスプレイなしのAIグラスがすでに出荷台数の過半
- XR市場のVR以外の部分は**+211.2%**成長
- Meta は**スマートグラス市場の69.2%(2026年Q1)**を保有。Ray-Ban Meta は2025年に**約700万本**販売
- スマートグラス市場: 2025年 $2.5B → 2026年 $3.2B → 2033年 $14.4B(CAGR 24.2%)
- Apple が2026年後半に参入表明(未発売)、Google/Samsungも音声先行の製品を秋に投入予定

**重要な解釈**: 勝ったのは「**仮想世界に入る**」体験ではなく、「**現実世界にAIを重ねる**」デバイスでした。つまりメタバースの遺産は**フィジカルAIとAIアシスタントに吸収された**と見るべきで、独立したメタトレンドとして追う価値は最も低いです。

| **AAPL** | Apple | Vision Proは商業的に失敗。2026年後半のスマートグラスが再挑戦 |

**米国のバリュー候補 → EssilorLuxottica**
「AIグラスのブームが続いても、眼鏡が売れ続ける限り本業は無事」という**下方硬直性**が最大の魅力。META をメタバース銘柄として買う理由はもうありません(AI銘柄としてなら別)。

VTuber2社は「株価が下がった=割安」に見えますが、**格下げの理由は成長率の鈍化**であり、バリュートラップ(安く見えるだけの罠)の典型的な形をしています。日本のメタバース市場は2026年に1兆円超と言われますが、その2割がVTuber関連という構成で、**産業インフラではなくコンテンツ景気**です。トレンドとして追う対象ではありません。

## 6. 総合: バリュー株の抽出結果(まとめ表)

| テーマ | 米国のバリュー候補 | 日本のバリュー候補 |
|---|---|---|
| **電力(1位)** | **D** Dominion(PER19.9倍・Data Center Alley) | **9508** 九州電力(PER6.45倍/PBR0.8倍)、**9503** 関西電力(PBR0.74倍) |
| DC本体(2位) | **FIX** Comfort Systems(成長+57%でPER49倍) | **1969** 高砂熱学、**1980** ダイダン(PER16.9倍・受注残3,231億円) |
| 水(3位) | **XYL** Xylem(PER21-22倍) | **6370** 栗田工業(DC冷却水薬品を26年1月開始) |
| フィジカルAI(4位) | **TER** Teradyne(本業がキャッシュを生む) | **6273** SMC(PER23倍・相対的に最安) ※純粋なバリューは無し |
| メタバース(5位) | EssilorLuxottica(本業の眼鏡が下支え) | **該当なし** |

### もし1つに絞るなら

- **米国: Dominion Energy (D)** — 「確実に来る需要 × まだ公益株の値段」という歪みが最も大きい
- **日本: 九州電力 (9508) または 関西電力 (9503)** — PBR1倍割れが希少になった市場で、AI電力需要という触媒を持ちながら取り残されている

**共通する考え方**: 5つのテーマの中で、**電力だけが「AI投資が減速しても需要が残る」**という性質を持ちます。上のバブル論(capex強度34%、循環取引、減価償却)が現実化した場合、DC・フィジカルAI・メタバース関連は同時に大きく下げますが、電力は既存需要(EV・製造業回帰・空調)が下支えします。**同じテーマを買うなら、最も川上で、最も代替が効かない場所を買う**というのが今回の結論です。

## 7. 監視すべき指標(この結論が崩れるサイン)

1. **ハイパースケーラーのcapexガイダンス**(四半期ごと)。減額 → 全テーマに波及
2. **ハイパースケーラーのフリーキャッシュフローと社債発行額**。借金依存が進むほど持続性が下がる
3. **GPUの減価償却年数の変更**(会計方針の変更は利益に直撃)
4. **日本の原発稼働基数**(現在33基中9基)。ここが増えると電力株の利益が跳ねる
5. **電力のPPA(長期購買契約)の新規締結ペース**。止まったらDC建設が止まったサイン
6. **ヒューマノイドの「非管理環境」での稼働事例**。ここが出れば4位のフィジカルAIは順位が上がる
7. スマートグラスの出荷台数(メタバースではなくこちらが本流)
