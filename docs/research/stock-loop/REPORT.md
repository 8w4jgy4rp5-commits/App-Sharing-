## 3. 今回の反省 → method.md v3

### 🔴 最大の問題: 「弱気は当たるが、強気は当たらない」

2回分のデータが同じことを示しています。

| | 日本 | 米国 |
|---|---|---|
| 弱気の判断 | ✅ 機能(-0.72%) | ✅ 機能(-1.94%) |
| **強気 vs 中立** | ❌ 差 0.17pt | ❌ **中立が勝利** |

**解釈**: 「これは避けるべき」(赤字なのに株価3倍のSUMCO、中国が-20%減収のナイキ、上値余地3%の合併案件D)という判断は、根拠が具体的で外しにくい。
一方「これは買うべき」の判断は、**根拠がほぼ「PERが低い」の一点**で、それが機能していません。

**証拠**: CEGを「予想PER21.96倍でバリューではない」として中立にしたが、**全19銘柄でトップの+2.28%**。同じIPPでも、より安いTLN(10.24倍)・NRG(11.03倍)は下落。**セクター内では「安い順」ではなく「質の高い順」に上がった。**

→ **v3の変更**: 「PERが低い＝優先」を単独の強気根拠として使うのをやめる。低PERは**必要条件であって十分条件ではない**。強気にするには「安い」に加えて**具体的な触媒**(契約・再稼働・上方修正)を要求する。

### 🔴 自分で作ったルールを自分で破った

第1回で **R7「必ずベンチマーク対比で採点する」** を追加したのに、**今回そのベンチマークを計算できませんでした**。基準日(8/18)の日経平均とS&P500の水準を台帳に記録していなかったためです。
(参考: SPYは8/20に-0.84%、8/20終値$762.60。8/18の水準が無いため期間の超過リターンは**未計算**)

→ **v3の変更**: ledger.md にベンチマークの基準値を記録する欄を追加。
