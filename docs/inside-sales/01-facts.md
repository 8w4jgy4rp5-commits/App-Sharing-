# 01. 弾込めシート(テレアポで使えるファクト集)

Guidable Jobs のインサイドセールス用。**質問型営業のための材料置き場**であって、
そのまま読み上げる原稿ではない。ここの事実を「どう質問の形にするか」は `02-qa.md` で扱う。

> ⚠️ **数字の取り扱い注意**
> ここに載せた自社の数字は、社外の紹介記事・比較記事から拾ったもの。
> 公式サイト(guidablejobs.jp)には作業環境から接続できなかったため未確認。
> 媒体資料由来の古い数字が混ざっている可能性が高い(下表に矛盾あり)。
> **お客様に言う前に、必ず社内の最新の媒体資料で裏を取ること。**

## A. 自社(Guidable)の強み

| 項目 | 内容 | 確認状況 |
|---|---|---|
| ミッション | 「日本経済をもっと多国籍に」 | 社外記事 |
| 主力サービス | Guidable Jobs(在留外国人向け求人サイト)、Guidable Japan(自社メディア) | 社外記事 |

### 強みを一言でいうと
「集める」だけでなく **「選別して渡す」** ところまでやっている。
求人媒体(掲載して終わり)と人材紹介(高い成果報酬)の中間にいる。

## B. 【最重要】永住者という切り口の意味

**Guidable が売っているのは「永住権を持つ外国人材」。ここが全ての土台。**

| | 技能実習 / 育成就労 | 特定技能 | **永住者・身分系** |
|---|---|---|---|
| 就労制限 | 職種が限定 | 分野が限定 | **なし(何の仕事でもOK)** |
| 監理団体・支援機関 | 必要 | 登録支援機関が必要 | **不要** |
| 在留期間 | 有期 | 有期(1号は通算5年) | **無期限** |
| 転職 | 原則不可(育成就労で一部緩和) | 可 | **自由** |
| 受入企業の手続き | 煩雑 | 煩雑 | **日本人採用とほぼ同じ** |
| 日本語 | 来日直後が多い | 試験レベル | **生活が長い人が多い** |

### ここから導かれる、この商材の一番の勝ち筋

お客様の頭にある「外国人採用は大変そう」という **イメージの中身は、ほぼ全部
"技能実習・特定技能" の話**。永住者採用はそのどれにも当てはまらない。

つまり **お客様が断っている対象と、こちらが売っているものがズレている**。
テレアポで本当にやるべきは、説得ではなく **このズレを本人に気づいてもらうこと**。
→ 質問型営業と相性が非常に良い。「反論」ではなく「確認」で崩せる。

## C. マクロ状況(2026年8月時点)

### 外国人労働者
- **257万1,037人**(2025年10月末時点・厚生労働省、2026年1月30日公表)。**過去最高**
- 国籍1位: ベトナム 60万5,906人(全体の23.6%)
- 都道府県: 東京 58.6万人 / 愛知 23.0万人 / 大阪 17.5万人
- 産業別: **製造業が約1/4**。**医療・福祉は2021年から5年連続で20%超の増加率**(4年で2.5倍以上)

### 人手不足
- **人手不足倒産 2025年度 441〜442件で過去最多**(前年度350件から約1.3倍)
- 業種別: **建設112件(全体の25.4%)** / 物流52件 / 老人福祉21件 / 労働者派遣13件 / 美容11件 / 警備10件
- 原因の三大要因: 求人難・従業員退職・人件費高騰(人件費高騰は1.7倍増)
- 有効求人倍率(2026年5月): 全国平均 0.99倍 / **建設躯体工事従事者 7.55倍**

### 制度変更 — 育成就労制度
- **2027年4月施行**。技能実習制度は廃止
- 約3年の移行期間があり、**2030年頃までは技能実習と併存**
- 転籍が同一機関1〜2年勤務後に原則可能に(実習の転籍原則禁止から大幅緩和)
- 監理団体は「監理支援機関」として**新規に許可申請が必要**(自動移行ではない)
- 受入企業に外国人雇用管理アドバイザー設置等の**追加義務**。違反で受入停止処分

> 💡 **育成就労の使い方に注意**
> 育成就労は **Guidable の商材ではない**。「制度が変わって大変ですね」と煽ると、
> 「うちは実習生やってないので」で終わる。
> **対比の弾**として使う → 「制度に振り回されない採用手段もある」という位置づけ。

## D. お客様側の典型的な懸念(調査で出てきたもの)

1. 日本語コミュニケーション
2. 定着率
3. **就労ビザの申請方法が分からない**
4. **受け入れ後の社内体制の整え方が分からない**
5. 在留資格などの管理負担
6. 法的手続き(労働条件、法定福利、課税)の複雑さ

### 現行スクリプトとの照合

| 懸念 | 現行スクリプトの対応 |
|---|---|
| 日本語 | ✅ あり(①) |
| 文化面(遅刻・バックレ) | ✅ あり(②) |
| イメージがつかない | ✅ あり(③) |
| **定着率** | ❌ **無い** |
| **ビザ・手続き・社内体制** | ❌ **無い**(③の中で少し触れる程度) |

→ 埋めるべき穴が2つある。しかも永住者はこの2つに**特に強い**(在留期限なし=管理負担なし)。
→ `02-qa.md` で追加する候補。
