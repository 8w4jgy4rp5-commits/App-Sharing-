# 02. 受付突破(最大のボトルネック)

現状、**一番落ちているのは受付**。ここを先に直す。

> ⚠️ **ここでは質問型営業を使わない**
> 受付の方は決裁者でも当事者でもないので、課題をヒアリングする相手ではない。
> 受付がやっているのは「取り次ぐ / 切る」の二択の判断だけ。
> 質問型が効くのは②担当者トーク以降(→ `03-qa.md`)。

---

## A. 受付が判断していること

受付は電話の内容を **最初の5秒でしか聞いていない**。そこで見ているのは1つだけ。

> **「この人は、うちの担当者が知っている人か?」**

営業か否かではない。**知り合いかどうか**。だから判断材料はこの4つになる。

| 判断材料 | 「知り合い」のサイン | 「営業」のサイン |
|---|---|---|
| 担当者の名前 | **名前で指名する** | 「採用担当者様」と役職で聞く |
| 用件の長さ | 短い or 言わない | 長い説明 |
| 語尾 | **「お取次ぎお願いいたします」**(依頼で言い切る) | 「いらっしゃいますでしょうか」(疑問) |
| トーン | 平坦・言い切り | 語尾が上がる・へりくだる |

---

## B. 現行トークの分解

```
お世話になっております。ガイダブルの〇〇と申します。
「〇月頃」に採用関係でお話をさせていただいておりまして、
進捗のご報告も兼ねてお電話させていただいたのですが、
本日、採用担当者様はこちらにいらっしゃいますでしょうか?
```

**良く出来ている点**(ここは変えない)
- 「ガイダブルの」と株式会社を省いている → 既存取引先の言い方
- 「進捗のご報告」→ 継続案件の匂い
- 用件を「採用関係」とぼかしている

**切られている原因の仮説(優先度順)**

| # | 仮説 | 根拠 |
|---|---|---|
| **1** | **「採用担当者様」と役職で聞いている** | 名前を知らない=知り合いではない、と自白している。**これが最大の疑い** |
| **2** | **矛盾している** | 「以前お話しした」のに「名前を知らない」。**スクリプト自身に「お名前はお伺いできておりません」という言い訳の枝がある = 現場で頻繁に突かれている証拠** |
| 3 | 長い | 約100字。受付の判断は5秒。用件に入るまでが長い |
| 4 | 「採用」というワード | 受付は「採用」で求人営業と分類するよう教育されている会社が多い |
| 5 | 語尾が弱い | 「〜のですが」「〜でしょうか」。知り合いはこう話さない |

## C. 改善案(たたき台)

### 案A ── 名前を握れている場合【本命】

```
お世話になっております。ガイダブルの〇〇と申します。
〇〇様に、お取次ぎお願いいたします。
```

**用件を言わない。** これが一番強い。名前を知っている時点で「知り合い」判定になる。
現行スクリプトには既に「担当握り」の枝がある。**あれは1回目で名前を取り、2回目でこう使うための仕込み。**
→ つまり **1コール目のゴールを「アポ」ではなく「名前の取得」に置き直す**のが構造的な答え。

聞き返されたときだけ、当たり前のトーンで短く返す:
> 「1月に採用の件でご担当者様とお話しさせていただきました、そのご報告です。」

### 案B ── 名前が無い場合(短縮版・骨格はそのまま)

```
お世話になっております。ガイダブルの〇〇と申します。
1月に採用の件でお話しさせていただきました、そのご報告です。
採用ご担当の方に、お取次ぎお願いいたします。
```

約100字 → **約55字**。曖昧語を6つ削除し、全部を言い切りで終えている。

1. **曖昧語を全部落とした**(↓ B-1)
2. **「いらっしゃいますでしょうか?」→「お願いします。」**(↓ B-2)
3. 長い一文を2つに切った

### B-1【最重要】曖昧語 = 自信のなさ = 営業のサイン

受付は内容より「**この人は堂々としているか**」を見ている。
現行トークに並んでいるのは、全部**「断られる前に予防線を張る言葉」**。

| 現行 | 何が起きているか | 改訂 |
|---|---|---|
| 「〇月**頃**に」 | 自分の会社の履歴なのに曖昧。知り合いは日付を覚えている | 「**1月に**」 |
| 「お話をさせていただいて**おりまして**」 | 言い切らずに次へ流している | 「お話し**しました**」 |
| 「ご報告**も兼ねて**」 | 用件をぼかしている。「兼ねて」の相手が不明 | 「**そのご報告です**」 |
| 「お電話させていただいた**のですが**」 | 語尾が濁る。断られる前提の言い方 | 削除 |
| 「**本日**」「**こちらに**」 | 無くても通じる。長さが営業っぽさを生む | 削除 |

**言い切れない言葉は全部落とす。** これは受付だけでなく担当者トークにも効く。

### B-2【最重要】疑問文をやめて、依頼で止める

| | |
|---|---|
| ❌ 「担当者様、いらっしゃいます**でしょうか?**」 | **疑問文**。答える権利を受付に渡している。「おりません」の一言で即死できる |
| ⭕ 「〇〇様に、**お取次ぎお願いいたします。**」 | **依頼**。取り次がれるのが前提。断るには、こちらの前提を一度否定する労力が要る |

**守るべき一線は「依頼か疑問か」だけ。丁寧さは別のつまみなので、上げても構造は壊れない。**

| 形 | 判定 |
|---|---|
| ⭕ 「〇〇様に、**お取次ぎお願いいたします。**」 | 依頼。**これを標準にする** |
| ⭕ 「〇〇様、お願いします。」 | 依頼。最短だがぶっきらぼうに聞こえる |
| ❌ 「〇〇様に、お取次ぎ**いただけますでしょうか?**」 | **疑問に戻る。使わない** |
| ❌ 「〇〇様、いらっしゃいます**でしょうか?**」 | 疑問。元の形 |

**⚠️「お取次ぎ」を付けるのは問題ない。危ないのは「〜いただけますでしょうか」に流れること。**
**「お願いいたします」で言い切って終える。**丁寧語尾は伸ばしてよいが、疑問には変えない。

**なぜぶっきらぼうにしないのか(実務上の理由)**
テレアポは同じ会社に何度もかける。**受付との関係は資産。**
一度「感じの悪い人」と認識されると、その会社は以後ずっと繋がらない。
突破率を数%上げるために受付を敵に回すのは割に合わない。

- **トーンが伴わないと逆効果。** 平坦に、当たり前のことを言う調子で、**語尾を下げる**。
  「お願いします↑」だと結局お伺いになる
- **用件を聞かれる確率は上がるかもしれないが、それは悪いことではない。**
  用件を聞かれている = まだ切られていない。D の問答集で返せば会話は続く。
  「おりません」で即死されるよりはるかにマシ

### 案D ── 既存を装わない、正直な初回アプローチ【案Bと比較測定する】

```
お世話になっております。ガイダブルの〇〇と申します。
採用についてお伺いしたいことがございまして、
採用ご担当の方にお取次ぎお願いいたします。
```

**約35字。案Bよりさらに短い。**

#### なぜ効くか ──「聞きに来た人」は弾かれにくい

受付が弾いているのは「**売りに来た人**」。
**「お伺いしたいことがありまして」は、その分類にそのまま入らない。**
同じ電話でも立て付けが違って聞こえる。

#### 【重要】この案は E の矛盾を丸ごと消す

現行と案Bは「1月にお話しした件のご報告」と**既存を装っている。**そのため:

| 案B(既存を装う) | 案D(装わない) |
|---|---|
| 担当者に「そんな話は聞いていない」と言われる | **起きない** |
| E のリカバリートークが要る | **不要** |
| 月の運用ルール(1月固定・6か月以上前)が要る | **不要** |
| ①と②が矛盾する | **最初から整合する** |

E で挙げた選択肢2「①を正直な初回アプローチに変える。突破率は下がるが、以降が全部楽になる」の実装形。

#### ⚠️ トレードオフ ── 机上で決めない

**受付突破率は下がる可能性がある。**一般に既存を装ったほうが受付は通りやすい。
**ただしアポ率でどちらが良いかは不明。**突破しても担当者の入口で崩れれば意味がない。

→ **F の検証計画で、案B と案D を期間を分けて比較する。**

#### ⚠️ 備え ──「どういったことでしょうか?」

ここで説明を始めると、聞きに来たはずが売り込みになって崩れる。

> 「**採用のご状況について、ご担当者様に直接伺えればと思っておりまして。**」

**これで止める。**C-2 の原則どおり、受付にサービス説明はしない。

#### 名前が取れている場合は案Aが優先
案D は**名前が取れていない1回目**に使う。名前が取れたら案A(「〇〇様にお取次ぎお願いいたします」)が最強なのは変わらない。

### 案C ── 話し方(内容より効く可能性がある)

- **「お世話になっております」を言い切って、一拍置く。** 続けて名乗らない
- **語尾を下げる。** 上がると質問=お伺い=営業になる
- 冒頭に「恐れ入ります」を置かない。下手に出た瞬間に営業確定
- 早口にしない。急ぐほど「断られる前に言い切ろうとしている人」に聞こえる

## C-2【原則】受付にサービス説明はしない

**「外国人特化の求人サイトで…」を受付で言わない。** 理由は3つ。

### 1. 説明こそが「営業」と分類させる材料になる
受付は判定係。**用件が分からないと分類できないので切りにくい。**
「外国人特化の求人サイトを運営しておりまして」まで聞けた瞬間に分類が完了して切れる。
こちらから判定材料を差し出している。

### 2. 決める権限のない人に、断る材料を渡すことになる【最悪】
「外国人」は特に強い分類ワード。聞いた受付は「あー、うち外国人は採ってないので」と
**自分で判断して断る。**
だが受付は**外国人を採用するか決める立場ではない。**
本来は担当者が判断することを、権限のない人に肩代わりさせている。
しかも「今は採っていない」と「今後も採らない」は全く違うのに、受付にその区別はつかない。

### 3. 「1月にお話しした件」と矛盾する
**既に話したことがある相手に、自己紹介はしない。**
「1月にお話しした件のご報告です」の直後にサービス説明を始めれば、その場で嘘だとバレる。
**E で決めた路線とサービス説明は両立しない。**

### 食い下がられたとき

> 「採用のご提案になります。**詳しくはご担当者様にお伝えできればと思っております。**」

説明を求められて説明しないのは不自然に見えるが、逆。
**「これは担当者に話す内容だ」というメッセージになる。**受付に全部説明する人のほうが営業に見える。

### ⚠️ ただし嘘はつかない

| | |
|---|---|
| ⭕ **省略** | 「採用の件で」(嘘ではない。言っていないだけ) |
| ❌ **虚偽** | 「外国人ではありません」「営業ではありません」 |

省略はセーフ、否定はアウト。バレたときのダメージが違うし、担当者に繋がった後の信用にも響く。

> **「外国人特化」を言う場所は②担当者トーク。**
> 受付と担当者では、渡していい情報が違う。

## D. 受付の返しへの問答集

| 受付の言葉 | 返し | 意図 |
|---|---|---|
| 「ご用件をお伺いできますか?」 | 「1月に採用の件でご担当者様とお話しさせていただきました、そのご報告です。」 | 短く、当たり前のトーンで。**説明を足さない** |
| 「営業のお電話ですか?」 | 「採用のご提案も含みます。1月にお話しさせていただいた件のご報告でして、ご担当者様にお取次ぎお願いいたします。」 | **嘘をつかない。**「違います」は言わない。認めてすぐ本題に戻す |
| 「そういったお電話はお断りしています」 | 「承知しました。ありがとうございます。次回のために、ご担当者様のお名前だけ伺えますか?」 | **引きながら名前を取る。**これが次回の案Aの弾になる |
| 「担当者は不在です」 | (現行スクリプトの枝どおり)戻り時間 → 出社予定 → 手隙の時間 → **名前** | 現行のままでOK |
| 「そんな話は聞いていませんが」 | 「失礼しました。ご担当者様宛にお電話しておりまして、お名前まで伺えていませんでした。採用の件でご案内できればと思っております。」 | 受付相手では**説明しない**。担当者に言われた場合は E を使う |

## D-2「担当者は不在です」【最頻出・実例から追加】

### まず診断 ── 額面通りに受け取らない

**全社で担当者が不在、ということは統計的に起きない。**

| 正体 | |
|---|---|
| 本当に不在 | 外出・会議・休み |
| **婉曲な門前払い** | **「営業だな」と判断された。これが多い** |
| 担当者が決まっていない | 小さい会社など |

「だいたい不在」と言われるなら、**まだ受付段階で弾かれている可能性が高い。**
タイミングの問題ではなく突破の問題。
**ただし電話口で区別はつかないので、両方に効く手を打つ。**

### 取れるものは4つある ──「名前しかない」は違う

| | 取るもの | 取りやすさ |
|---|---|---|
| 1 | **戻り時間・出社予定** | ★★★ |
| 2 | **部署・役割** | ★★☆ ← **現行スクリプトに無い** |
| 3 | 名前 | ★☆☆ |
| 4 | 繋がりやすい時間帯 | ★★☆ |

**名前は一番取りにくい。** 個人情報であり、営業に渡すと受付が後で困るので警戒される。
**いきなり最難関を狙わない。**

### 文言の候補

#### A. 折り返し前提型【一番おすすめ】
> 「では〇時頃に改めます。**その際は、どちら宛にお伝えすればよろしいですか?**」

「お名前を教えてください」より **「どちら宛に」のほうが言いやすい。** 要求している感じが薄まる。

#### B. 理由先出し型(受付のためにする)
> 「承知しました。改めてお電話いたしますので、**お名前だけ伺ってもよろしいですか?**
> 次回お取次ぎいただくときに、お手間を取らせずに済むかと思いまして。」

**「自分のため」ではなく「受付の人のため」という立て付けにするのが肝。**

#### C. 部署・役割から入る型
> 「ちなみに、採用のご担当は**人事の方でしょうか。それとも現場の責任者の方**でしょうか?」

**二者択一なので答えやすい。**個人情報のハードルも低い。
取れれば次回「人事部の方にお取次ぎお願いします」と精度が上がる。

#### D. 時間だけ取る型(確実性重視)
> 「いえ、お戻りでしたらこちらから改めますので、**お戻りの時間だけ伺えますか?**」

**「伝言は結構です」と先に言うのがポイント。**受付の負担が減るので協力してもらいやすい。

#### E. 直通を聞く型(ダメ元)
> 「その時間に改めます。**直通のお電話などございますか?**」

取れれば**受付を丸ごとスキップできる。**

### ⚠️ カマかけ型は、C-2 の線引きを越える

> 「ご担当は〇〇部の方でしたよね?」と**知っているふりをして訂正を誘う**手法。
> よく使われるし効くが、**C-2 の「省略はセーフ、否定はアウト」を越える。**
> 知らないのに知っているふりをするのは、省略ではなく積極的な偽装。
> **そして案D(正直な初回)とは完全に矛盾する。**案Dを使うならこの手は使えない。

### 【最重要】1コールで1つだけ

1本の電話で「名前+戻り時間+部署」を全部聞くと**尋問**になる。受付に嫌われて終わり。

| | ゴール |
|---|---|
| 1回目 | **戻り時間だけ** |
| 2回目 | 「**〇時頃と伺ったのですが**」→ **継続性が生まれる** → 部署を聞く |
| 3回目 | 名前 |

**「〇時頃と伺ったのですが」が効く。**前回の会話を引き継いでいる = もう初対面ではない。
→ **不在は失敗ではなく、次への布石として設計する。**

### 時間帯を疑う

「だいたい不在」なら、**かけている時間帯が悪い**可能性がある。

| 時間帯 | |
|---|---|
| 朝一(9:00〜9:30) | 出社直後で席にいる確率が高い。ただし朝礼中のことも |
| 昼(12:00〜13:00) | 避ける |
| 夕方(17:00〜18:00) | 戻っている確率が高い |
| 月曜午前 / 金曜夕方 | 避ける |

**推測せず記録する。** → `04` の記録項目に**架電した時間帯**を入れてある。

## E. ①と②の矛盾 ── 対応方針【決定済み】

受付には「**以前お話しした件のご報告**」と言っているが、
②担当者トークの冒頭は「弊社、〜求人サイトを運営しておりまして」と**完全な初回説明**になっている。

受付が「以前お話しした件の報告だそうです」と取り次ぐと、担当者は「?」の状態で電話に出る。
そこで初回説明が始まると、**騙された感**が出て、その後の質問型営業が効かなくなる。

受付突破率だけ上げても、ここで落ちれば意味がない。選択肢は3つ:

1. **②の冒頭を合わせる** — 「以前ご案内させていただいた件で」と繋げる(修正が小さい)
2. **①を正直な初回アプローチに変える** — 突破率は下がるが、以降が全部楽になる
3. **そのままにする** — 受付が用件を詳しく伝えないケースに賭ける

### ✅ 決定 ── 3(そのまま)+ リカバリートークを用意する

突破率を維持したまま、突かれたときだけ吸収する方針。

**担当者に「そんな話は聞いていない」と言われたときの返し:**

> 「失礼しました。前回から半年以上空いてしまっておりまして、
> **こちらのご連絡が行き届いていなかったかもしれません。**
> 改めて簡単にご説明させていただいて**もよろしいですか?**」

**設計意図**
- **主語を相手ではなく、こちらに置く。** 「記憶が曖昧かと思いますので」だと、言い方次第で
  「忘れたあなたが悪い」に聞こえる。こちらの非にすれば角が立たない
- **最後を質問で終える。** 宣言ではなく質問にすると小さな「はい」がもらえ、聞く姿勢に入ってくれる。
  **ここが質問型営業の入り口になる**(→ `03-qa.md` に接続)

**✅ 月の運用ルール【決定】**

**言う月は、時期によって2つを切り替える。**

| 現在の時期 | 言う月 | 実際の間隔 |
|---|---|---|
| **7月〜12月** | **1月**(同年) | 6〜11か月 |
| **1月〜6月** | **6月**(**前年**) | 7〜12か月 |

| ルール | 理由 |
|---|---|
| **上の2つ以外は使わない。会社ごとに変えない** | 会社ごとに変えると、次回架電したときに前回と食い違う |
| **必ず6か月以上前になるようにする** | 「半年以上空いて」というリカバリートークと整合させるため |
| **「頃」を付けない。「1月に」と言い切る** | 「頃」は自分の会社の履歴すら曖昧という自己申告になる(→ B-1) |

**⚠️ 境界の注意**
7月に「1月」と言うと**ちょうど6か月**でギリギリになる。
気になる場合は**7月中は「6月(前年)」のまま**にして、切り替えを8月にすると安全。

(2026年8月時点 → 「1月」= 7か月前)

**⚠️ この返しは担当者相手のもの。**
受付に突かれたときは説明せず「1月に採用の件でお話しさせていただきました、そのご報告です。」で止める。
受付に長く話すと切られる。

## F. 検証のしかた(ここが「失敗のフィードバック」の第一歩)

**一度に1つしか変えない。** 全部同時に変えると、何が効いたか永久に分からなくなる。

### 進め方
1週間(または100コール)ごとに、変更を1つだけ入れて比較する。

| 週 | 変えるもの |
|---|---|
| 1週目 | 現状のまま計測(**基準値を取る**) |
| 2週目 | 案C(話し方)だけ |
| 3週目 | 案B(短縮・既存風)だけ |
| 4週目 | **案D(正直な初回)だけ** ← 案B と直接比較する |
| 5週目 | 案A(1コール目は名前取りに専念) |

### ⚠️ 案B と案D は、受付突破率だけで判断しない

案D は突破率が下がっても、**担当者に繋がった後が崩れない。**
→ **両方について「受付突破率」と「担当者接触後のアポ率」を並べて比較する。**
最終的に見るのは**コール数あたりのアポ数**。

### 記録する項目

```
日付 / コール数 / 受付突破数 / 担当者接触数 / アポ数
切られた理由: [用件を聞かれた / 一律お断り / 不在 / 担当者に断られた]
```

**「切られた理由」を毎回1語で残すこと。** これが溜まると、次に直す場所が推測ではなく事実で決まる。

## G. 架電前のリサーチはどこまでやるか

**結論: 1社60秒。それ以上はかけない。**

テレアポは分母のゲーム。1社10分かけて100点のトークをするより、
1社1分で80点のトークを10社にかけたほうがアポは多く取れる。
まして今のボトルネックは受付。**受付突破に効くリサーチはほとんど存在しない**ので、
深く調べた情報は、担当者に繋がらない限り丸ごと無駄になる。

### 見るのはこの4つだけ

| # | 見るもの | 時間 | 何に使うか |
|---|---|---|---|
| **0** | **社内の架電履歴** | 20秒 | **前回誰が出て何を言われたか。担当者名が取れていないか。外部より先に見る** |
| 1 | 求人の有無(Indeed・求人ボックスで社名検索) | 20秒 | ②の最初の質問の答えが先に分かる。「拝見しました」が言える |
| 2 | 業種(建設 / 物流 / 介護・福祉 / 製造 か) | 10秒 | マクロの弾が刺さるか |
| 3 | 拠点(一都三県・大阪か) | 10秒 | 訪問提案か Zoom か |

担当者名は調べるより**受付に聞いたほうが速い**。採用ページに載っていればラッキー程度。

### リサーチしすぎの弊害

1. コール数が落ちる(1社10分 × 20社 = 3時間)
2. **調べた情報を使いたくなり、喋りすぎる** ← 一番厄介
3. 準備した分だけ、断られたときに引きずる

2 は質問型営業と真っ向からぶつかる。調べた情報は**語るためではなく、質問するために使う**。

> ❌ 「御社、〇〇の求人を出されていますよね。弊社は永住者に特化しておりまして…」(説明)
> ⭕ 「〇〇の求人を拝見したのですが、あちらはもうお決まりですか?」(質問)

同じ情報でも、後者は相手が喋る。

### 正しい配分 ── 前は薄く、接触してから厚く

| タイミング | かける時間 |
|---|---|
| 1回目の架電前 | **60秒**(上の4つだけ) |
| 名前が取れた / 担当者と話せた後 | **5分**(次のコールで使う) |
| 商談前 | しっかり調べる |

最初から全社を深く調べるのは、**まだ生きているか死んでいるか分からないリードに等しく時間を配っている**状態。
脈のある相手にだけ厚くする。
