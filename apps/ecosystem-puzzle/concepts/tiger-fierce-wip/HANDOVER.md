## いちばん大事な前提 —「こわもて」の中身

ユーザーが出した参照は**ジョジョ（荒木飛呂彦作品のアニメ）のキャラ顔**2枚。
ここを外すと全部やり直しになるので必ず読むこと。

**参照から読み取るべきなのは「吠える獣」ではない。**

| ○ こういうこと | × こうではない |
|---|---|
| 表情は**静か**。凄みは冷めた目つきだけから出る | 牙を剥いて咆哮 |
| **半眼。細いが横に長い目**。瞳は小さく白目が多い | まん丸の目、大きい瞳 |
| 上まぶたが**太い線**で、**目尻の線が目の外まで伸びる**。二重の線が入る | 上下対称のレンズ型 |
| 影は**ハードエッジ**だが色は**中間の茶**。影の形が頬骨と鼻筋を**削り出す** | 真っ黒なベタ影、貼った四角 |
| 線は**細くて綺麗**。目の下や口元に細い皺線 | 太い均一な線 |
| 顔立ちが**リアル寄りで大人っぽい・面長** | 丸くてかわいい |
| 口は**ほぼ水平で片端だけ上がった冷笑** | への字（＝不機嫌に見えて失敗した） |

著作権があるので**造形を似せない**。借りるのは描き方の文法だけ。

## 構図の決定

**体は真横（右向き）のまま、顔だけこちらを振り向かせた3/4。**
真横顔では凄みが出ないのと、これなら既存の子トラと決定的に別物になるため。

## いまの到達点

- 顔: **`face-h.svg` が現時点の最良**（a→h の8案。a〜e は方向を履き違えていた分なので参考程度）
- 体: **`tiger-v8.svg`。作り直しが必要**

### 顔の変遷で得た知見（同じ失敗を繰り返さないため）

1. **輪郭まで多角形にすると木彫りのお面になる。** 輪郭は滑らかな曲線、角張らせるのは内側の影と模様だけ（a〜c で失敗 → d で解決）
2. 模様が多いと部族マスクになる。額の縞は5本まで、頬は左右2本まで
3. 眉を太くすると目が潰れる
4. 口をへの字にすると「不機嫌」になる。水平＋片端上げ

### face-h に残っている宿題

1. まだ丸い。もっと面長・頬骨を高く・顎を細く
2. 頬の影がまだ「貼った形」に見える。削り出しのテーパー形状に
3. 冷たさが足りない。まだ「眠そうな猫」寄り
4. マズル（口まわりの白）が大きく、顔の下半分を占めすぎ
5. 奥側（画面右）の情報量が少なく、平たく見える

### tiger-v8（体）の既知の不具合

1. **縞が暴発**。`src/stripes.py` の `length` と `bend` が大きすぎて放射状の針になっている。短く・細く・ほぼ平行に
2. **後ろ脚に腹のクリームが流れ込んで白い柱**になっている（クリップ範囲のミス）
3. 下あごが頭から分離して見える（※ただし顔は3/4に作り直すので v8 の頭部は捨てる）
4. 前脚のつま先の刻み線が不自然

## ファイルの場所と作り方

```
concepts/tiger-fierce-wip/
  HANDOVER.md        ← これ
  face-*.png         レンダリング結果（a→h）
  tiger-v8.png       体の現状
  00-existing-tiger.png  既存の子トラ（被らせない対象）
  faces2.html        ブラウザ比較用
  src/
    face-*.svg       顔のソース（face-h.svg が最良）
    tiger-v8.svg     体のソース
    build.py         体のSVGを生成（stripes.py を読む）
    stripes.py       縞の生成。ここの数値を直す
    render.sh        SVG → PNG
```

### レンダリング

```sh
sh src/render.sh src/face-h.svg face-h.png 760 700
```

中身はヘッドレスChromeのスクリーンショット。背景透過。
（画像生成ツールがない環境のため、SVG手描き → Chromeで描画 → 目視 → 修正 のループで進めている）

### ブラウザで見る

```sh
cd concepts/tiger-fierce-wip && python -m http.server 8777 --bind 127.0.0.1
```
→ `http://127.0.0.1:8777/faces2.html`
（`file://` はブラウザ操作ツールが開けないのでローカルサーバー経由にする）
