How to use

  1. Add a listing as soon as you find it. The name is enough to start — you can fill in the rest later.
  2. Read the table across, one row at a time. On a phone, swipe it sideways — the row names stay on the left.
  3. After a viewing, press Edit on that column and write down what you actually thought while it is fresh.
  4. Ruled one out? Press Remove twice on that column, so only real options are left.

The lowest rent gets a Lowest mark automatically. Everything is saved in this browser. If you are signed in to CobbleWorks, it also follows you to your other devices.
