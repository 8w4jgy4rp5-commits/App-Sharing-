Work Notes

Keep one private note per work topic and add what you learn each day, so scattered lessons pile up into your own handbook.

How to use
  1. Create a note for a topic you keep running into — not for a single day.
  2. Whenever you notice something, open that note and add one line to it.
  3. Each note shows how many times you added to it, so you can see which ones are growing.
  4. Pin the notes you rely on, and search when the list gets long.

Your notes are private to you. They are saved in this browser, and synced to your other devices while you are signed in to CobbleWorks.
