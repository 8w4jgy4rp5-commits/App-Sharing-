How to use

  • ⇒ Fill in Hook, Summary, Discussion Points, and Reflection
  • ⇒ Add a Source Link (http:// or https:// only)
  • ⇒ Watch the character count — 280 is the limit; full-width characters and emoji count as 2, links always count as 23
  • ⇒ Tap Copy on each block
  • ⇒ Paste as your main post on X, then paste each block as a reply
  • ⇒ Your draft auto-saves, so it's safe to close the tab and come back later
