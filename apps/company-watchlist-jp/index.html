How to use
  • Add a company you're interested in using the form below.
  • Add its 4-digit securities code (optional) to get a "Check price" link.
  • Click the status badge on a card to cycle Watching → Top Choice → Follow Up.
  • Click the code badge or the notes text on a card to edit them inline.
  • Use the industry search box and filter buttons to narrow down the list.
  • Use Export/Import backup to move your data to another browser or device.
